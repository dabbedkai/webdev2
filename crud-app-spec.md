# Task Tracker Application Specification

## Project Description
The Task Tracker Application is a web-based management system designed to track productivity tasks, assigned priorities, and completion statuses. It allows users to create new tasks, view all active tasks, modify task details, and remove completed or obsolete tasks.

## Functional Requirements
* **REQ-1 (Create):** The system shall allow users to create a new task with a title, detailed description, priority level (1 to 5), and completion status.
* **REQ-2 (Read):** The system shall display all created tasks in a formatted catalog table showing their title, priority, status, and management action links.
* **REQ-3 (Update):** The system shall allow users to edit existing task details via a pre-populated form and update the task list upon validation.
* **REQ-4 (Delete):** The system shall allow users to delete a task permanently from the system list by selecting its corresponding delete action.
